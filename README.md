# Capture The Flag (CTF) Exercise

Welcome to the Capture The Flag (CTF) exercise! In this challenge, you will be tasked with exploiting a cloud-hosted website to uncover a secret. Please read the instructions carefully and follow the guidelines below.

## Challenge Overview

You are provided with the following resources:

- A cloud-hosted website: [https://hello-anya.fly.dev](https://hello-anya.fly.dev)
- The source code of the website
- The first three letters of the secret: **"19b"**
- The name of the text file that holds the secret: **"secret_file"**

Your objective is to exploit the cloud-hosted website to find the complete secret.

## Requirements

1. **Understanding the Code**:

   - Review and understand the provided source code in order to identify potential vulnerabilities.

2. **Exploitation**:

   - Use your knowledge of web application security to find, exploit any vulnerabilities and interact with the cloud-hosted website to find the hidden secret.

3. **Submission**:
   - After successfully finding the secret, you are required to submit your findings via email. Your submission should include:
     - The answer: the complete value of the secret.
     - A short explanation of how you discovered the secret.

## Hint

- Pay special attention to the `pages_controller.rb` file, as it contains critical information that may assist you in your quest to identify potential vulnerabilities.

## Bonus Challenge

- As a bonus, if you can create a script that automates the process of finding the secret identifying the potential vulnerabilities, it will be considered as a big plus in your submission.

Good luck, and may the best candidate win!
